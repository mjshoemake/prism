# Prototypes

Stand-alone experiments kept for reference. They are **not** part of the app build and load
React/Bootstrap/Chart.js from CDNs, so open them directly in a browser (or via `npm run dev` at
`http://localhost:5173/prototypes/<file>.html`).

| File | What it is |
|---|---|
| `metrics-legacy.html` | The original single-file app this project was refactored from (Oct 2026). |
| `metrics-dashboard-split.html` | Split-pane dashboard layout experiment. |
| `charts-demo.html` | Chart.js styling experiments. |
| `theme-demo.html` | Showcase of the purple/black Bootstrap theme. |
| `purple-black-theme.css` | Copy of the theme the pages above link to (the app uses `src/theme/`). |
